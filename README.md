# BEV-WAM

Project website for **BEV-WAM: A Bird's-Eye-View World-Action Model for Autonomous Driving**.

**A Latent is a World.** A unified BEV spatiotemporal representation connects world prediction, geometry-conditioned observation decoding, and driving planning.

Live website: https://eipha-technology.github.io/bev-wam/

## Local preview

This is a buildless static website. Run `python -m http.server 8000` from this directory, then visit http://localhost:8000.

## Deployment

GitHub Pages serves the root of the `main` branch. All assets use relative paths and the website needs no external services or JavaScript dependencies.

## Content

The website summarizes the accompanying BEV-WAM presentation dated November 1, 2026. Benchmark numbers are presentation-reported results, not independently verified leaderboard rankings. Videos are qualitative demonstrations. Paper, model weights, and training code are not provided by this website.

The camera-layout illustration is schematic, not a calibrated sensor configuration. Geometry controls shown on the website illustrate the representation; actual model outputs appear in the video sections.
